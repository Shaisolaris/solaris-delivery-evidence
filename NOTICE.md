# Notices

This focused Solaris Technologies plugin derives five Python runtime
modules from the MIT-licensed Solaris Dev Shop revision recorded in PROVENANCE.json.
The recorder uses caller labels instead of requiring a full staff directory; other runtime modules are unchanged.
SOURCE-NOTICE.md retains the upstream project's notices. The full role library is
not installed by this companion. Its 61 specialists and coordinator remain in the
[full DevShop](https://github.com/Shaisolaris/solaris-dev-shop).
